A short poem about agency: the power to choose and to act, as it
passes between two agents who agree on one plan. One holds the map,
the other holds the door; each chooses a part of the plan, and when
one drops the thread the other's hand is already there.

`main.py` (Python 3.13, standard library only) writes the poem to
`/output/entry.txt`. Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Two runs write byte-identical output. The poem is 210 Unicode characters,
inside the 1–280 gate, and not only white space.
